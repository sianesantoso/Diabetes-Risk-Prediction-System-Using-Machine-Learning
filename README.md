# 🩺 Diabetes Risk Prediction System Using Machine Learning

A machine learning web application that predicts diabetes risk based on patient health information.  
This project uses a trained machine learning model and Streamlit to provide an interactive prediction interface.

## 🚀 Features

- Predict diabetes risk using patient health data
- Interactive web interface using Streamlit
- Display prediction probability
- User-friendly input form

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Machine Learning
- Pickle

## 📊 Input Features

The model uses the following features:

- Gender
- Age
- Hypertension
- Heart Disease
- Smoking History
- BMI
- HbA1c Level
- Blood Glucose Level
